# ATM Interface – Java Development Internship Task 3

This project is a console-based ATM Interface developed using Java.

## Features
- User login with User ID and PIN
- Account balance inquiry
- Cash deposit
- Cash withdrawal
- Fund transfer
- Transaction history
- Account login lock after three failed attempt

## Technologies Used
- Java
- Object-Oriented Programming(OOP)
- Eclipse IDE
