# Number Guessing Game

## Oasis Infobyte Internship – Java Development
**Task 2**

## Project Description
The Number Guessing Game is a simple Java console application in which the computer generates a random number between 1 and 100. The player tries to guess the number within a limited number of attempts

## Features
- Random number generation between 1 and 100
- Maximum of 7 valid attempts per round
- Hints such as Too High and Too Low
- Displays a success message when the correct number is guessed
- Reveals the correct number if the player loses
- Option to play again
- Tracks rounds and cumulative score
- Validates user input

## Technologies Used
- Java
- Java Standard Library
- Eclipse IDE

## How to Run
1. Open Eclipse IDE
2. Import the project into your workspace
3. Open `src/NumberGuessingGame.java`
4. Run the file as a Java Application
